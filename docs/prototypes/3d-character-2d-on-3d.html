2D-on-3D character prototype

Selected direction: keep the body and head dimensional, but render the face as a graphic 2D treatment mapped onto the 3D head. Characters default to facing the bonfire and can rotate freely around the Y axis.

Tap a character to select. Drag left/right to rotate. Use Face fire to restore the default heading.
Character 1 - facing fireDefault heading points directly at the bonfire.
Prototype intent: the 2D face should inherit the existing Read My Bible avatar language rather than becoming more realistic. The production implementation should reuse saved avatar identity inputs (face shape, hair, glasses, facial hair, skin and colors) while keeping the scene character performant and readable at distance.
